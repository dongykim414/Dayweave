# Harness experiments

이 폴더는 AI 코딩 Agent의 작업 결과가 아니라 작업 방식과 하네스 변경 효과를
관찰하기 위한 자료를 보관합니다.

## 운영 원칙

1. 한 번에 작고 평가 가능한 작업 하나를 요청합니다.
2. 작업마다 관찰 프로토콜을 사용합니다.
3. 관찰 가능한 증거만 실행 로그에 기록합니다.
4. 한 번의 실수는 기록만 하고, 반복되는 실수에 대응해 하네스를 변경합니다.
5. 가능하면 한 번에 하네스 조건 하나만 변경합니다.
6. 변경 전후에 비슷한 작업을 실행해 차이를 비교합니다.

## 디렉터리

- `observation-protocol.md`: 실시간 관찰 기준과 마스터 프롬프트
- `templates/run-log.md`: 작업별 기록 템플릿
- `runs/`: 실제 작업 실행 기록

## 기록 대상

- 요청 해석과 명시된 성공 조건
- 확인한 파일과 발견한 사실
- 수정 전 계획
- 실제 변경 범위
- 실행한 명령과 결과
- 실패 단서, 대응, 재검증
- 완료 근거와 남은 위험

내부 추론이나 숨겨진 사고과정을 요구하거나 기록하지 않습니다.
