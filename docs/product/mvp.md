# Dayweave MVP

## 제품 목표

사용자가 Todo와 일정을 한곳에서 만들고 관리하며, 일·주·월 보기로 자신의 시간을
쉽게 파악할 수 있는 모바일 다이어리 앱을 제공합니다.

## 대상 사용자

- 개인 일정과 해야 할 일을 함께 관리하고 싶은 사용자
- Android와 iOS 기기에서 일정을 빠르게 확인하고 싶은 사용자

## MVP 기능

### Calendar

- 일간, 주간, 월간 보기
- 이전 및 다음 기간 이동
- 오늘로 이동
- 날짜 선택
- 일정 생성, 조회, 수정, 삭제
- 제목, 날짜, 시작 시간, 종료 시간, 메모 입력
- 종일 일정

### Todo

- Todo 생성, 조회, 수정, 삭제
- 완료 및 미완료 전환
- 선택적인 마감일

### Experience

- 기기 로컬 저장
- Android와 iOS 우선 대응, Expo Web은 개발·검증 보조 수단으로 사용
- 터치 조작과 모바일 접근성 고려
- 잘못된 시간 범위 등 기본 입력 검증

## MVP 제외 범위

- 회원가입과 로그인
- 서버 데이터베이스
- 여러 기기 간 동기화
- 반복 일정
- 외부 캘린더 및 SNS 연결
- 일정 공유와 공동 편집
- 푸시 알림과 모바일 위젯
- AI 기능
- 드래그 앤 드롭

제외 기능은 포기한 기능이 아니라 핵심 일정 모델과 UI가 안정된 후 추가할 기능입니다.

## 완료 조건

- 사용자가 일·주·월 보기를 전환할 수 있습니다.
- 일정과 Todo를 생성, 수정, 삭제할 수 있습니다.
- Todo 완료 상태를 변경할 수 있습니다.
- 앱을 종료하고 다시 실행해도 로컬 데이터가 유지됩니다.
- 주요 사용자 흐름에 대한 자동 검증이 존재합니다.
- lint, typecheck와 지원 플랫폼 빌드 검증이 통과합니다.
