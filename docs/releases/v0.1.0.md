# Dayweave v0.1.0 — M0 Foundation

- 날짜: 2026-09-08
- 상태: Foundation pre-release
- Milestone: [M0 Foundation](https://github.com/dongykim414/Dayweave/milestone/1)
- 관련 PR: [#1 Expo 전환과 release workflow](https://github.com/dongykim414/Dayweave/pull/1), [#2 M0 Foundation](https://github.com/dongykim414/Dayweave/pull/2)

## 이 버전의 의미

`v0.1.0`은 완성된 다이어리 앱이 아니라, 이후 기능을 일관된 구조와 자동 검증 위에서
개발할 수 있게 만든 첫 공식 기준선입니다. PR #1이 실행 기반을 Next.js에서 Expo로
전환했고, PR #2가 제품·아키텍처 경계와 4탭 UI 셸을 완성했습니다.

## 포함된 결과

- React Native + Expo SDK 57 + Expo Router 실행 기반
- `오늘`, `타임라인`, `아바타`, `내 정보` 4탭 route와 screen 분리
- Sky Theme, semantic color token, ThemeProvider
- 기능에 종속되지 않는 공용 UI primitive
- semantic Mood ID와 파츠형 Avatar domain 타입
- 제품·디자인·아키텍처·개발·로드맵 문서
- Harness 관찰 규칙, run log와 학습 문서
- pnpm 11, frozen lockfile, Expo dependency check, lint, typecheck, Web export CI
- PR 기반 개발과 Weekly Release Cut 자동화

## 검증 근거

- `pnpm install --frozen-lockfile`: 성공
- `pnpm deps:check`: 성공
- `pnpm lint`: 성공
- `pnpm typecheck`: 성공
- `pnpm build:web`: 성공, 네 개 탭을 포함한 static route 생성
- GitHub Actions `Validate Expo app`: PR에서 성공

Android SDK·연결 기기가 없어 Android 실제 화면은 확인하지 않았고, Windows 환경이라
iOS 로컬 네이티브 빌드도 실행하지 않았습니다. 이는 Web과 정적 검증을 통과했다는
사실과 구분해 남깁니다.

## 이번 버전에 포함하지 않은 것

- Diary CRUD와 SQLite persistence
- 사진 선택과 저장
- MoodSelector와 Mood 시각 자산
- Avatar renderer, customization, ownership
- 로그인, Supabase, cloud sync
- 결제, AI, 일정·SNS·기기 연결, 선택 공유, push notification

## 실행 방법

Node.js 22와 pnpm 11 환경에서 다음을 실행합니다.

```bash
pnpm install --frozen-lockfile
pnpm dev
```
