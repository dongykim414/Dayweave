# Dayweave v0.2.0-alpha.1 — M1 Diary Core

- 날짜: 2026-09-09
- 상태: M1 integration pre-release
- Milestone: [MVP v1 — Personal Diary & Schedule](https://github.com/dongykim414/Dayweave/milestone/2)
- 관련 PR: [#3 M1 Diary Core](https://github.com/dongykim414/Dayweave/pull/3), [#4 v0.2.0-alpha.1 release metadata](https://github.com/dongykim414/Dayweave/pull/4)

## 이 버전의 의미

`v0.2.0-alpha.1`은 M0의 앱 셸 위에 최초의 실제 제품 기능을 통합한 미리보기입니다.
Today에서 오늘의 감정, 50자 한 줄과 선택적 긴 글을 기록하고 같은 날짜의 기록을
수정할 수 있습니다. Android/iOS는 SQLite를, Web preview는 localStorage를 사용합니다.

## 포함된 결과

- semantic Mood ID, Default Mood Pack과 MoodSelector
- device local calendar date 기반 DiaryEntry
- Mood·한 줄·긴 글 중 하나 이상을 요구하는 domain validation
- Android/iOS SQLiteProvider와 `PRAGMA user_version` migration
- `UNIQUE(entry_date)`와 upsert 기반 하루 한 기록 규칙
- Web preview 전용 localStorage repository
- loading, saving, error와 성공 feedback을 포함한 Today form
- Jest domain test와 PR CI test gate

## 알려진 제한

- Android/iOS 실제 기기의 저장·앱 재실행·복원 acceptance는 아직 완료하지 않았습니다.
- Web localStorage는 브라우저 데이터 삭제 시 함께 사라지며 기기 간 동기화되지 않습니다.
- 사진, Timeline CRUD, Calendar, 공유, 로그인과 cloud sync는 포함하지 않습니다.
