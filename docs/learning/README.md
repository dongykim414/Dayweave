# Dayweave Learning Notes

이 경로는 기능 결과뿐 아니라 개발 과정의 판단을 학습 자료로 남깁니다. 각 milestone
또는 중요한 작업은 별도 하위 폴더를 사용합니다.

학습 문서는 가능한 한 다음 질문에 답합니다.

1. 무엇을 변경했는가?
2. 왜 지금 이 작업이 필요했는가?
3. 어떤 대안을 검토했는가?
4. 선택한 방식의 장점과 비용은 무엇인가?
5. 실제 코드와 명령으로 어떻게 확인하는가?
6. 다음 작업에서는 어떤 결정이 이어지는가?

## 현재 자료

- [M0 Foundation 학습 요약](setup/m0.md)

## Harness Run과의 차이

- `docs/harness/runs`: AI가 실제로 무엇을 관찰하고 실행했는지 짧고 객관적으로 기록
- `docs/learning`: 그 기술과 의사결정을 사람이 이해하고 재사용할 수 있도록 자세히 설명

Run Log는 증거 중심이고 Learning Note는 이해 중심입니다. 같은 사실을 사용하더라도
목적이 다르므로 서로 대체하지 않습니다.
